# Tapbox Стат MCP

Официальный плагин Tapbox Стат для подключения ИИ-агентов к аналитике мессенджера MAX: каналы, чаты, публикации и боты.

MCP-сервер работает по адресу `https://beta.stat.tapbox.ru/api/mcp` (Streamable HTTP, JSON-RPC 2.0). В этом репозитории только манифесты плагинов, настройки подключения, навык для агента и документация. Сервер и данные остаются в инфраструктуре Tapbox.

## Что умеет

- подбирать каналы и чаты по тематике, региону и размеру аудитории с сортировкой по подписчикам, охвату, ERR, индексу цитирования и приросту;
- показывать карточку канала и динамику подписчиков, ERR и публикаций;
- сравнивать до шести каналов по одним метрикам;
- искать по текстам всех публикаций: точная фраза, минус-слова, период;
- разбирать ленту канала и отдельный пост с кривой набора просмотров;
- показывать, кто упоминает и репостит канал, и из чего сложился индекс цитирования;
- искать ботов в каталоге MAX;
- сообщать остаток лимитов по ключу.

## Ключ

Для работы нужен API-ключ вида `tbx_…`. Ключи выдаёт команда Tapbox Стат. Выданные на ваш аккаунт ключи, их лимиты и расход видны в профиле: [beta.stat.tapbox.ru/my/profile](https://beta.stat.tapbox.ru/my/profile).

Не добавляйте настоящий ключ в файлы репозитория и не вставляйте его в текст запроса нейросети.

## Установка

### Claude Code

```bash
claude plugin marketplace add justtake88/tapbox-mcp
claude plugin install tapbox-stat@tapbox
```

При установке Claude Code спросит «Ключ Tapbox Стат» и сохранит его как секрет. Без интерактивного вопроса ключ передаётся флагом:

```bash
claude plugin install tapbox-stat@tapbox --config api_key=tbx_...
```

Сменить ключ позже — `/plugin configure tapbox-stat`. Проверить подключение — `/mcp`. В уже открытой сессии после установки выполните `/reload-plugins`.

Плагин подключает MCP-сервер и навык `tapbox-stat`, который подсказывает агенту, какой инструмент брать под задачу.

### Codex

Сохраните ключ в переменной окружения до запуска Codex:

```bash
export TAPBOX_API_TOKEN="tbx_..."
```

```powershell
$env:TAPBOX_API_TOKEN = Read-Host "Ключ Tapbox Стат" -MaskInput
```

Добавьте маркетплейс и установите плагин:

```bash
codex plugin marketplace add justtake88/tapbox-mcp
codex plugin add tapbox-stat@tapbox
```

### Gemini CLI

```bash
gemini extensions install https://github.com/justtake88/tapbox-mcp
```

Gemini спросит «Ключ Tapbox Стат» как чувствительную настройку и передаст его в заголовок авторизации. После установки перезапустите Gemini CLI и проверьте сервер через `/mcp`.

## Подключение без плагина

Claude Code одной командой:

```bash
claude mcp add --transport http tapbox https://beta.stat.tapbox.ru/api/mcp \
  --header "Authorization: Bearer tbx_..."
```

Codex, файл `~/.codex/config.toml`:

```toml
[mcp_servers.tapbox]
url = "https://beta.stat.tapbox.ru/api/mcp"
bearer_token_env_var = "TAPBOX_API_TOKEN"
```

Любой клиент, который умеет задавать HTTP-заголовки:

```json
{
  "mcpServers": {
    "tapbox": {
      "type": "http",
      "url": "https://beta.stat.tapbox.ru/api/mcp",
      "headers": {
        "Authorization": "Bearer tbx_..."
      }
    }
  }
}
```

## Инструменты

| Инструмент | Что делает |
| --- | --- |
| `list_categories` | Тематики каналов с числом каналов |
| `list_regions` | Регионы с числом каналов |
| `search_channels` | Подбор каналов и чатов по тематике, региону, аудитории и метрикам |
| `get_channel_overview` | Карточка канала: подписчики, охват, ERR, индекс цитирования, прирост |
| `get_channel_metrics` | Динамика подписчиков, ERR, сводка и расписание публикаций |
| `compare_channels` | Сравнение 2–6 каналов |
| `search_posts` | Полнотекстовый поиск по публикациям |
| `list_channel_posts` | Лента канала за период с просмотрами |
| `get_post_overview` | Разбор поста: кривая просмотров и цитирования |
| `analyze_mentions` | Кто упоминает и репостит канал |
| `get_citation_index` | Индекс цитирования и его разбор |
| `get_market_overview` | Сводка по всей базе MAX |
| `list_bot_categories` | Категории каталога ботов |
| `search_bots` | Поиск ботов по названию, описанию и категории |
| `get_bot_overview` | Карточка бота, лайки и похожие боты |
| `get_account_usage` | Остаток лимитов по ключу, не расходует квоту |

Все инструменты только читают данные.

## Примеры запросов

- «Подбери 10 каналов MAX про финансы от 20 тысяч подписчиков с ERR выше 15%, покажи таблицей».
- «Сравни newmedia и mash по подписчикам, охвату, ERR и индексу цитирования. Кого выгоднее взять под рекламу?»
- «Найди посты за последний месяц, где упоминается наш бренд, и сгруппируй по каналам».
- «Кто вырос сильнее всех за неделю? У кого рост не сходится с числом постов и цитированием?»
- «Подбери трёх ботов MAX для записи клиентов и сравни их по лайкам».

## Проверка

Зависимостей и шага сборки нет. После изменений запустите:

```bash
python3 scripts/validate.py
claude plugin validate .
```

Подробности и готовые сниппеты для других клиентов — на [beta.stat.tapbox.ru/mcp](https://beta.stat.tapbox.ru/mcp).
