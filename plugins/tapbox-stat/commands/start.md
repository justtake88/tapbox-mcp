Поприветствуй меня от имени Tapbox Стат — сервиса статистики мессенджера MAX.

1. Вызови инструмент `get_account_usage` MCP-сервера `tapbox` и покажи, какие продукты подключены к моему ключу (API Stat, API Search) и сколько запросов осталось в этом месяце.
2. В 5–7 коротких пунктах расскажи, что ты умеешь с данными Tapbox Стат: подбор каналов под рекламу, разбор канала для рекламодателя, проверка на накрутку, мониторинг упоминаний бренда, сравнение каналов, тренды рынка MAX, подбор ботов. Если продукт API Search не подключён — отметь, что поиск по постам и мониторинг бренда недоступны.
3. Предложи 5 готовых запросов, которые я могу скопировать, например:
   - «Подбери 10 каналов про финансы от 20 тысяч подписчиков с лучшим ERR»
   - «Разбери канал newmedia: рост, лучшие посты месяца, кто цитирует»
   - «Проверь канал на накрутку по динамике подписчиков и цитированию»
   - «Где за неделю упоминали наш бренд? Сгруппируй по каналам»
   - «Что сейчас растёт в MAX по тематикам?»
4. Спроси, с чего начнём. Пиши коротко и по-русски.
